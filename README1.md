# XAI-Based Loan Approval and Credit Scoring System

An Explainable AI (XAI) pipeline using **Random Forest**, **SHAP**, and **LIME** to provide global model governance and individual decision transparency for credit risk modeling.

## 🚀 Features
- **Binary Classification**: Predicts loan approval status (`Approved` vs `Denied`).
- **Global Transparency (SHAP Bar Plot)**: Ranks overall feature influence across all applicants.
- **Local Decision Explanations (SHAP Waterfall)**: Quantifies exact metric contributions per individual applicant.
- **Rule Explanations (LIME HTML Report)**: Provides human-readable approval/denial reasoning.
